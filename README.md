# ReadUP · ReadTech Companion

**นวัตกรรมแอปพลิเคชันช่วยฝึกอ่านและประมวลผลคำสำหรับเด็กที่มีความบกพร่องทางการเรียนรู้**

ฝึกทีละคำ พัฒนาไปทีละขั้น อ่านได้อย่างมั่นใจ

## รุ่นทดลอง 0.1.0

เว็บ React + TypeScript + Vite โทนชมพู–ขาว รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

- มีแบบฝึก **5 บทแรก / 25 กิจกรรม**: รู้จักพยัญชนะ ฟังแล้วเลือก จับคู่ด้วยการแตะ แยกรูปคล้าย และพยัญชนะต้นจากภาพ
- แสดงแผน **6 LEVEL / 30 บทเรียน** อีก 25 บทระบุชัดเจนว่าอยู่ระหว่างเตรียม ไม่มีแบบฝึกที่แสร้งว่าพร้อมใช้
- ตัวช่วย 3 ระดับ ไม่หักดาว ไม่แข่งขัน ไม่จับเวลานับถอยหลัง
- ตอบถูกแต่ละข้อได้ 1 ดาว แสดงดาวเด้งหนึ่งดวงกลางหน้าจอและทำนองฉลองสั้น ๆ มีเสียงนุ่มเมื่อกดปุ่ม ปิดเสียงเอฟเฟกต์แยกจากเสียงอ่านได้ ดาวไม่แสดงเมื่อตอบไม่ตรงหรือข้ามข้อ สรุปดาวตามจำนวนที่ทำได้จริง
- เคารพ `prefers-reduced-motion` และโหมดสงบ (ดาวแสดงแบบนิ่ง) ผู้ใช้ใหม่เปิดดาวเด้งเป็นค่าเริ่มต้น ผู้ใช้เดิมเก็บการตั้งค่าโหมดสงบไว้ตามเดิม หากต้องการดาวเด้งให้ปิดโหมดสงบในหน้าปรับการใช้งาน
- บันทึกใน IndexedDB บนเครื่องเดิม ฝึกต่อได้หลังพักหรือเปิดหน้าใหม่ แยกทำได้เองครั้งแรก / หลังลองใหม่ / หลังช่วย / เก็บไว้ฝึกภายหลัง
- รายงานในเครื่อง ส่งออก CSV ภาษาไทย และครูเพิ่มข้อสังเกตได้
- ขนาดสัมผัสใหญ่ รองรับคีย์บอร์ด มี focus indicator, modal focus trap, reduced motion และตัวอักษรขยาย

## ข้อจำกัดที่ต้องทราบก่อนใช้กับผู้เรียน

1. เป็นต้นแบบฝึกกิจกรรม ไม่ใช่เครื่องมือวินิจฉัยหรือผลรับรองประสิทธิผล ไม่ใช้คะแนนเลือกคำตัดสินการอ่านออกเสียง
2. รองรับชุดเสียงครูใน `public/audio/` ผ่าน `src/data/audio.json` โดยใช้ก่อนเสียงสังเคราะห์ แต่ **ยังไม่มีชุดเสียงที่ครูตรวจรับ** ในรุ่นนี้ ขณะนี้ใช้ `speechSynthesis` ของอุปกรณ์ เลือกเสียงไทยและปรับความเร็ว 0.65–1.10 เท่าได้ ครูต้องตรวจการออกเสียงก่อนใช้จริง หากไม่มีเสียงไทยใช้ตัวช่วยและผู้ดูแลอ่านให้ฟัง ไม่ส่งข้อความไปบริการ TTS ที่แอปจัดหาเอง แต่บริการเสียงของอุปกรณ์อาจประมวลผลออนไลน์ตามระบบนั้น ดูวิธีเพิ่มไฟล์และแหล่งเสียงใน `public/audio/README.md`
3. ไม่มีการเข้าถึงไมโครโฟน บันทึกเสียง รู้จำเสียง บัญชีครู ฐานข้อมูลกลาง PWA/offline cache หรือ Pre-test/Post-test ในรุ่นนี้
4. ผลเป็นข้อมูลของผู้เรียนคนเดียวบน browser/device นี้ ไม่ซิงก์ข้ามเครื่อง อาจหายเมื่อล้างข้อมูลเบราว์เซอร์ มี warning หากบันทึกไม่ได้
5. ครูเปิดดูผลบนเครื่องนี้ได้โดยไม่ล็อกอิน หน้านี้ **ไม่ใช่ระบบควบคุมสิทธิ์** อย่าใช้เพื่อเก็บข้อมูลอ่อนไหว และไม่กรอกชื่อจริง/ประวัติสุขภาพ
6. ก่อนสลับผู้เรียน ให้ส่งออก CSV เก็บส่วนตัว แล้วล้างผลโดยยืนยันในหน้าปรับการใช้งาน (กู้คืนในแอปไม่ได้)
7. ความเข้ากันได้และการเข้าถึงต้องทดลองบนเครื่องจริงก่อนใช้กับเด็ก ไม่ได้อ้างว่าผ่าน WCAG หรือการประเมินทางคลินิก

## พัฒนาในเครื่อง

```bash
npm ci
npm run dev
```

เปิด URL `/ReadUP/` ที่ Vite แสดง

```bash
npm test
npm run build
npm run preview
```

ทดสอบผ่าน Chromium (รวม responsive, resume, CSV และ axe accessibility checks):

```bash
npx playwright install chromium
npm run test:browser
```

การตรวจอัตโนมัติไม่ทดแทนการทดสอบกับผู้เรียนและอุปกรณ์จริง

## Deploy บน GitHub Pages

1. ไปที่ **Settings → Pages → Build and deployment → Source → GitHub Actions** (ทำครั้งแรกโดยผู้ดูแล Repository)
2. Push เข้า `main` หรือกด **Actions → Test and deploy ReadTech Companion → Run workflow**
3. Workflow จะติดตั้ง dependencies, ทดสอบ, build และ deploy
4. URL หลัง deploy สำเร็จ: https://ictcs52.github.io/ReadUP/

`vite.config.ts` ใช้ `base: '/ReadUP/'` ไม่ต้องใช้ custom domain แอปใช้การสลับหน้าในเครื่องโดยไม่สร้าง URL ย่อยที่ทำให้ Pages 404

หาก deploy แจ้งว่า Pages ยังไม่ได้เปิด ให้ทำขั้นตอนที่ 1 แล้วรัน workflow อีกครั้ง หากมี environment approval ต้องให้ผู้ดูแลอนุมัติตามการตั้งค่า ไม่ข้ามขั้นตอนการป้องกัน

## เพิ่มหรือแก้บทเรียน

- `src/data/lessons.json`: แผน 30 บทและ 5 บทที่เล่นได้จริง
- `src/App.tsx`: กลไกกิจกรรม ตัวช่วย หน้ารายงาน และรางวัล
- `src/domain.mjs`: การคำนวณผล การสลับตัวเลือก และส่งออก CSV
- `src/storage.ts`: การบันทึก IndexedDB
- `src/components/Art.tsx`: ภาพ SVG ต้นฉบับสำหรับไก่ ม้า ปลา เรือ ใบไม้ และมาสคอตหนังสือ
- `src/styles.css`: responsive layout / accessibility styles
- `tests/domain.test.mjs`: ตรวจโครงสร้างเนื้อหาและการคำนวณผล

ก่อนเพิ่มคำที่มีสระ/วรรณยุกต์ ให้แยกการประสมเสียงกับการเรียงรูปคำ ใช้ข้อมูลตำแหน่งที่ครูตรวจแล้ว ไม่แยกสตริงไทยเป็นบัตรโดยอัตโนมัติ

## แผนระยะถัดไป

ให้ครูตรวจชุดคำและภาพ ทดลอง 5 บทกับผู้เรียนโดยผู้ดูแลกำกับ → เพิ่มเสียงตัวอย่างที่ตรวจรับ → ปรับกิจกรรมจากข้อสังเกต → เพิ่ม LEVEL 2–6 → ประเมินก่อน/หลังและเพิ่ม backend ส่วนตัวเมื่อจำเป็นต้องติดตามข้ามอุปกรณ์
