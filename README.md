# ReadUP · ReadTech Companion

**นวัตกรรมแอปพลิเคชันช่วยฝึกอ่านและประมวลผลคำสำหรับเด็กที่มีความบกพร่องทางการเรียนรู้**

ฝึกทีละคำ พัฒนาไปทีละขั้น อ่านได้อย่างมั่นใจ

## รุ่นทดลอง 0.2.0 · บัญชีครูและฐานข้อมูลกลาง

เว็บ React + TypeScript + Vite โทนชมพู–ขาว รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

- LEVEL 1–4 ฝึกพยัญชนะ สระ ประสมคำ และอ่านคำจากภาพ; LEVEL 5–6 ฝึกประโยคและความเข้าใจ
- ใช้งานได้ครบ **6 LEVEL / 30 บทเรียน / 150 กิจกรรม** ตั้งแต่ตัวอักษรถึงประโยคและความเข้าใจ รวมเรียงประโยค เติมคำ อ่านทีละช่วง เลือกภาพ เรียงเหตุการณ์ และเรื่องสั้น
- ตัวช่วย 3 ระดับ ไม่หักดาว ไม่แข่งขัน ไม่จับเวลานับถอยหลัง
- ปุ่มฟังและช่วยอยู่ด้านบนทุกบท ส่วนปุ่มต่อไปอยู่หลังผลตอบกลับ ลองใหม่ล้างสิ่งที่เลือกแต่รักษาจำนวนครั้งที่ลองและตัวช่วย กลับหน้าแรกได้โดยเก็บรอบไว้ฝึกต่อ
- ตอบถูกแต่ละข้อได้ 1 ดาว แสดงดาวเด้งหนึ่งดวงกลางหน้าจอและทำนองฉลองสั้น ๆ มีเสียงนุ่มเมื่อกดปุ่ม ปิดเสียงเอฟเฟกต์แยกจากเสียงอ่านได้ ดาวไม่แสดงเมื่อตอบไม่ตรงหรือข้ามข้อ สรุปดาวตามจำนวนที่ทำได้จริง
- เคารพ `prefers-reduced-motion` และโหมดสงบ (ดาวแสดงแบบนิ่ง) ผู้ใช้ใหม่เปิดดาวเด้งเป็นค่าเริ่มต้น ผู้ใช้เดิมเก็บการตั้งค่าโหมดสงบไว้ตามเดิม หากต้องการดาวเด้งให้ปิดโหมดสงบในหน้าปรับการใช้งาน
- บันทึกใน IndexedDB บนเครื่องเดิม ฝึกต่อได้หลังพักหรือเปิดหน้าใหม่ แยกทำได้เองครั้งแรก / หลังลองใหม่ / หลังช่วย / เก็บไว้ฝึกภายหลัง
- รายงานในเครื่อง ส่งออก CSV ภาษาไทย และครูเพิ่มข้อสังเกตได้
- ครูบันทึกการมีส่วนร่วมและความมั่นใจจากพฤติกรรมที่เห็นได้ โดยเว้นว่างเมื่อยังไม่ได้สังเกต กรองวันที่ร่วมกับกราฟอ่านถูก/อ่านข้าม/ความช่วยเหลือ ประวัติ และ CSV พร้อมบริบทชุดคำและจำนวนคำ (กราฟแสดง 30 ครั้งล่าสุดในช่วงที่เลือก)
- รางวัลคำนวณจากผลฝึกเดิม: ถ้วยบทละ 1 ใบเมื่อทำครบทุกข้อ เหรียญภารกิจละ 1 เหรียญ วันฝึกต่อเนื่องนับเมื่อทำกิจกรรมได้อย่างน้อย 1 ข้อตามวันประเทศไทย และเก็บเวลาตอบรายข้อใหม่เพื่อรองรับรอบที่ฝึกข้ามวัน ผลเก่าที่ไม่มีเวลาตอบใช้วันจบ/เริ่มรอบพร้อมข้อความอธิบาย รางวัลแยกผู้เรียนและตามผลกลางเมื่อเปลี่ยนเครื่อง
- เตือนพักทุก 5 นาทีที่ฝึกจริง เลือก 10 นาทีหรือปิดในปรับการใช้งานได้ ไม่รวมช่วงพัก/ซ่อนหน้าเว็บ/ออกจากกิจกรรม และฝึกต่อจากข้อเดิมโดยเก็บจำนวนครั้งที่ลองกับตัวช่วยไว้
- ประเมิน Pre-test/Post-test โดยครู: สร้างชุดพร้อมคะแนนเต็มและวิธีประเมินครบ 5 ด้าน เกณฑ์คงเดิมในชุด บันทึกผลก่อนแล้วหลัง พร้อมจำนวนคำ เวลาอ่าน และความช่วยเหลือ ตารางและ CSV แสดงผลต่างเป็นจุดเปอร์เซ็นต์เมื่อครูยืนยันเทียบกันได้ แก้ผลก่อนแล้วต้องยืนยันการเปรียบเทียบใหม่ รักษาสิทธิ์ครูเจ้าของและตรวจ revision โดยยังไม่มีข้อสอบอัตโนมัติ
- รายงานกลางมีแบบบันทึกการอ่านจริงโดยครู แยกจากคะแนนเกม: จำนวนคำอ่านถูก/ผิด การสลับตัวอักษร คำที่ข้าม การหยุดกลางคัน เวลาอ่าน และระดับความช่วยเหลือ พร้อมประวัติ แก้ไข และ CSV คำนวณอ่านถูกจากคำทั้งหมด เทียบเป้าหมายเบื้องต้น 80% โดยไม่ปัดขึ้นเพื่อให้ผ่านเกณฑ์
- บัญชีครูผ่าน Supabase Auth พร้อมรายชื่อครูที่ผู้ดูแลอนุมัติ และโปรไฟล์ผู้เรียนแยกรายคน
- ผล LEVEL 1 ซิงก์กลางเมื่อกำหนด Supabase แล้ว มีสำเนาในเครื่องระหว่างส่งและการตรวจ revision ป้องกันฉบับเก่าเขียนทับฉบับใหม่
- ผู้เรียนและบัญชีครูมีหน้าตั้งค่าการเชื่อมต่อสำหรับผู้ดูแล พร้อม SQL migration และคู่มือใน `docs/CLOUD_SETUP.md`
- ขนาดสัมผัสใหญ่ รองรับคีย์บอร์ด มี focus indicator, modal focus trap, reduced motion และตัวอักษรขยาย

## ข้อจำกัดที่ต้องทราบก่อนใช้กับผู้เรียน

1. เป็นต้นแบบฝึกกิจกรรม ไม่ใช่เครื่องมือวินิจฉัยหรือผลรับรองประสิทธิผล ไม่ใช้คะแนนเลือกคำตัดสินการอ่านออกเสียง
2. รองรับชุดเสียงใน `public/audio/` ผ่าน `src/data/audio.json` โดยใช้ก่อนเสียงสังเคราะห์ มีไฟล์ทดลองคำถาม **“ปลา เริ่มต้นด้วยเสียงอะไร?”** ในบทที่ 5 ข้อ 2 แล้ว รองรับชื่อไฟล์ไทยและ M4A คำอื่นยังใช้ `speechSynthesis` ของอุปกรณ์ เลือกเสียงไทยและปรับความเร็ว 0.65–1.10 เท่าได้ ครูต้องตรวจการออกเสียงก่อนใช้จริง หากไม่มีเสียงไทยใช้ตัวช่วยและผู้ดูแลอ่านให้ฟัง ไม่ส่งข้อความไปบริการ TTS ที่แอปจัดหาเอง แต่บริการเสียงของอุปกรณ์อาจประมวลผลออนไลน์ตามระบบนั้น ดูวิธีเพิ่มไฟล์และแหล่งเสียงใน `public/audio/README.md`
3. ไม่มีการเข้าถึงไมโครโฟน บันทึกเสียง รู้จำเสียง PWA/offline cache หรือข้อสอบ Pre-test/Post-test อัตโนมัติในรุ่นนี้ บัญชีครูและฐานข้อมูลกลางต้องติดตั้ง Supabase ตามคู่มือก่อนใช้
4. โหมดทดลองเดิมเก็บผลใน browser/device เดียว ไม่ซิงก์ข้ามเครื่อง โหมดครูที่เลือกโปรไฟล์ใช้ Supabase แยกตามครู/ผู้เรียน ก่อนเปลี่ยนเครื่องให้รอจนผลส่งครบ และใช้โหลดผลล่าสุดเพื่ออ่านผลกลาง
5. โหมดทดลองเปิดผลได้โดยไม่ล็อกอิน ใช้รหัส/ชื่อเรียกแทนข้อมูลอ่อนไหว โหมดฐานข้อมูลกลางต้องเข้าสู่ระบบครูที่ได้รับอนุมัติ และเปิด RLS ตาม migration ก่อนใช้เก็บข้อมูลจริง
6. ในโหมดทดลอง ก่อนสลับผู้เรียนให้ส่งออก CSV แล้วล้างผลโดยยืนยัน ในโหมดครูเลือกโปรไฟล์ผู้เรียนเพื่อสลับโดยไม่ล้างผล ออกจากระบบเพื่อล้างสำเนาส่วนตัวในเครื่อง; หากยังมีผลรอส่งจะให้ส่งออกก่อน
7. ความเข้ากันได้และการเข้าถึงต้องทดลองบนเครื่องจริงก่อนใช้กับเด็ก ไม่ได้อ้างว่าผ่าน WCAG หรือการประเมินทางคลินิก

## พัฒนาในเครื่อง

```bash
npm ci
npm run dev
```

เปิด URL `/ReadUP/` ที่ Vite แสดง

```bash
npm test

npm run preview
```

ทดสอบผ่าน Chromium (รวม responsive, resume, CSV และ axe accessibility checks):

```bash
npx playwright install chromium
npm run test:browser
```

การตรวจอัตโนมัติไม่ทดแทนการทดสอบกับผู้เรียนและอุปกรณ์จริง

## Deploy บน GitHub Pages

1. ไปที่ **Settings → Pages → Build and deployment → Source → GitHub Actions** (ทำครั้งแรกโดยผู้ดูแล Repository)
2. Push เข้า `main` หรือกด **Actions → Test and deploy ReadTech Companion → Run workflow**
3. Workflow จะติดตั้ง dependencies, ทดสอบ, build และ deploy
4. URL หลัง deploy สำเร็จ: https://ictcs52.github.io/ReadUP/

`vite.config.ts` ใช้ `base: '/ReadUP/'` ไม่ต้องใช้ custom domain แอปใช้การสลับหน้าในเครื่องโดยไม่สร้าง URL ย่อยที่ทำให้ Pages 404

หาก deploy แจ้งว่า Pages ยังไม่ได้เปิด ให้ทำขั้นตอนที่ 1 แล้วรัน workflow อีกครั้ง หากมี environment approval ต้องให้ผู้ดูแลอนุมัติตามการตั้งค่า ไม่ข้ามขั้นตอนการป้องกัน

## เพิ่มหรือแก้บทเรียน

- `src/data/lessons.json`: บทเรียน 30 บทที่เล่นได้จริง
- `src/App.tsx`: กลไกกิจกรรม ตัวช่วย หน้ารายงาน และรางวัล
- `src/domain.mjs`: การคำนวณผล การสลับตัวเลือก และส่งออก CSV
- `src/storage.ts`: การบันทึก IndexedDB
- `src/components/Art.tsx`: ภาพ SVG ต้นฉบับสำหรับไก่ ม้า ปลา เรือ ใบไม้ และมาสคอตหนังสือ
- `src/styles.css`: responsive layout / accessibility styles
- `tests/domain.test.mjs`: ตรวจโครงสร้างเนื้อหาและการคำนวณผล

ก่อนเพิ่มคำที่มีสระ/วรรณยุกต์ ให้แยกการประสมเสียงกับการเรียงรูปคำ ใช้ข้อมูลตำแหน่งที่ครูตรวจแล้ว ไม่แยกสตริงไทยเป็นบัตรโดยอัตโนมัติ

## แผนระยะถัดไป

ครูลงทะเบียนและแจกบัญชีนักเรียน → ทดลอง LEVEL 1 แยกผู้เรียนพร้อมกันหลายเครื่อง → ครูกำหนดเกณฑ์และบันทึกผลก่อน–หลัง พร้อมผลการอ่านจริง → เพิ่ม LEVEL 2–6 และชุดเสียงที่ตรวจแล้ว

## ฐานข้อมูลกลาง

ดู [คู่มือตั้งค่า Supabase](docs/CLOUD_SETUP.md) และ [SQL migration](supabase/migrations/202610060001_readtech_cloud.sql)

`public/cloud-config.json` ตั้งค่ากลางสำหรับโปรเจกต์ ReadUP แล้ว ครูทุกเครื่องเข้าสู่ระบบด้วยอีเมลและรหัสผ่านได้โดยไม่ต้องกรอก Project URL / Publishable key เอง ค่าการเชื่อมต่อเป็นค่าสาธารณะ สิทธิ์ข้อมูลตรวจด้วยบัญชีครูและ RLS ไม่ใช้ Secret/service_role key ใน frontend

ทดสอบฐานข้อมูลด้วย PostgreSQL ฝังตัว (PGlite) เพื่อยืนยัน RLS, สิทธิ์ครู, ownership, การปฏิเสธ anonymous และการตรวจ revision ส่วน browser tests ใช้ API จำลองสำหรับหลายผู้เรียน/หลายเครื่อง/ผลรอส่ง การผ่านชุดทดสอบนี้ยังไม่เท่ากับการเชื่อมโปรเจกต์จริง

## นักเรียนเข้าเรียนเอง

ครูเปิด **เข้าสู่ระบบ → เลือกครู → ผู้เรียน → เพิ่มผู้เรียน** แล้วส่งรหัสเข้าเรียนและรหัสผ่านที่สร้างให้เด็ก ผู้เรียนเดิมใช้ **สร้างบัญชีเข้าเรียน** โดยไม่ย้ายผลเดิม นักเรียนใช้ **เข้าสู่ระบบ → เลือกนักเรียน → รหัสเข้าเรียน + รหัสผ่าน** ได้เอง ครูดูผลผ่านรายชื่อของตน ออกรหัสผ่านใหม่ และพัก/เปิดบัญชีได้ ดูขั้นตอนติดตั้ง migration และ Edge Function ใน [คู่มือตั้งค่า](docs/CLOUD_SETUP.md)

เว็บเปิดหน้าเข้าสู่ระบบเป็นหน้าแรกเมื่อยังไม่มีบัญชีที่ได้รับสิทธิ์ ใช้แบบฟอร์มเดียวสำหรับครูและนักเรียน ก่อนเข้าสู่ระบบเปิดได้เฉพาะหน้าเข้าสู่ระบบและข้อมูลแนะนำ ส่วนบทเรียน รางวัล ผลฝึก รายงานครู และรายชื่อผู้เรียนแสดงหลังตรวจสิทธิ์แล้ว
